## 4강. 데이터결합과 관계

**관계**와 **조인**이라는 두 가지 방법으로 데이터를 결합할 수 있다.
두 가지 방법 모두 서로 다른 테이블을 결합하지만

즉 관계로 데이터를 결합할 때 원본 데이터를 조금 더 독립적으로 활용할 수 있다.


> **🧞‍♀️ 어떤 경우에 관계를, 어떤 경우에 조인을 사용하나요?**

```
관계는 각 테이블의 독립성을 유지하면서 유연하게 데이터를 분석하고 싶을 때 사용한다. Tableau가 시각화에 필요한 순간에 자동으로 조인을 수행하기 때문에 데이터 활용이 동적이다.
반면 조인은두 테이블을 공통 키를 기준으로 하나의 테이블처럼 직접 결합해야 할 때 사용한다. 
```



## 5강. 데이터결합과 조인

<!-- 데이터 결합과 조인에 대해 알게 된 점을 적고, 아래 질문에 답해보세요 :) -->

일반적으로 Tableau에서는 데이터를 결합할 때 **관계**방식 사용을 권장한다. 

하지만 데이터 결합 방식을 직접 제어하거나, 특정 조건에 따라 데이터를 필터링하거나 중복 데이터를 의도적으로 처리해야 하는 경우에는 **조인**을 사용하기도 한다.
조인을 설정하려면 데이터 소스 화면에서 테이블을 우클릭하여 ‘열기(Open)’를 선택한 후, 테이블을 드래그 앤 드롭하여 결합할 수 있다. 
이때 조인 방식은 **Inner Join, Left Join, Right Join, Full Outer Join**등 다양한 형태로 설정할 수 있다.

## 6강. 데이터결합 혼합

<!-- 데이터결합 및 혼합에 대해 알게 된 점을 적어주세요 -->

**데이터 혼합**은 관계나 조인과 달리 데이터를 실제로 하나의 테이블로 결합하지 않는 방식이다. 
대신 각 데이터 원본에서 데이터를 독립적으로 집계한 후, 그 결과를 하나의 시트에서 함께 시각화할 수 있도록 한다.
따라서 데이터 혼합에서는 실제로 결합된 새로운 데이터 원본이 생성되는 것이 아니라, **시각화 화면에서만 여러 데이터 원본의 결과가 함께 표시되는 형태**로 나타난다.

## 7강. 데이터 결합과 유니온

<!-- 유니온에 대해 알게 된 점을 적어주세요 -->

유니온을 사용하려면 결합하려는 테이블들의 구조가 동일해야 한다. 
즉, 각 테이블의 필드 수가 같고, 대응되는 필드의 이름과 데이터 유형이 일치해야 한다.

이러한 조건이 충족되면 여러 테이블의 데이터를 행 단위로 위에서 아래로 쌓아 하나의 테이블로 결합할 수 있다.

또한 여러 테이블을 한 번에 유니온하려면 **와일드카드***기능을 사용할 수 있다. 
이는 특정 패턴과 일치하는 테이블들을 자동으로 찾아 한 번에 유니온하는 방법이다. 예를 들어 대문자 O로 시작하는 모든 테이블을 유니온하고 싶다면 일치 패턴에 O*를 입력하면 된다.

> **🧞‍♀️ 유니온을 사용하기 위한 전제 조건은 무엇인가요?**

```
유니온을 사용하기 위해서는 결합하려는 테이블들의 구조가 동일해야 한다. 
즉, 각 테이블의 필드 수가 같고, 대응되는 필드의 이름과 데이터 유형이 서로 일치해야 한다. 
```


## 8강. 라이브와 추출

<!-- 라이브와 추출에 대해 알게 된 점을 적어주세요 -->

**라이브 연결**과 **추출 연결**의 가장 큰 차이는 데이터 업데이트 방식과 성능 처리 방식이다.

라이브 연결은 Tableau가 데이터 원본 데이터베이스에 직접 연결하여 데이터를 조회하는 방식이다. 

따라서 데이터 원본에 변경이 발생하면 대시보드에도 실시간으로 반영된다. 

또한 데이터가 Tableau 서버에 복사되지 않고 모든 처리 과정이 데이터베이스에서 수행되기 때문에 데이터베이스 성능에 영향을 받는다.

---

반면 추출 연결은 데이터 원본의 데이터를 Hyper 파일 형태로 추출하여 Tableau 서버나 로컬에 저장한 후 분석하는 방식이다.

이 경우 데이터를 미리 복사해 두기 때문에 집계,필터,계산 등 분석 작업을 빠르게 수행할 수 있다. 

다만 데이터가 자동으로 실시간 업데이트되지 않기 때문에 원본 데이터의 변경 사항을 반영하려면 추출을 새로 고침해야 한다.
 
> **🧞‍♀️ 라이브와 추출 방법의 차이가 무엇인가요? 어떤 경우에 추출을 사용하면 좋을까요?**

```
라이브 연결은 Tableau가 데이터베이스에 직접 연결하여 데이터를 조회하는 방식으로, 데이터 원본의 변경 사항이 실시간으로 반영된다. 반면 추출 연결은 데이터를 Hyper 파일 형태로 추출하여 로컬이나 서버에 저장한 후 분석하는 방식이며, 원본 데이터가 변경되면 새로 고침을 통해 업데이트해야 한다.

추출 방식은 데이터가 로컬에 저장되어 집계, 필터, 계산 등의 처리 속도가 빠르기 때문에 대규모 데이터셋을 분석하거나 성능이 중요한 분석 환경에서 사용하면 좋다.
```



**참고자료 : 온프레미스 데이터란?**

기업이나 조직이 자체적으로 보유한 물리적 서버나 데이터 센터 내에서 직접 관리하는 데이터로, 조직 내의 하나 이상 서버에서 통제됩니다. 본 서버들은 기업의 데이터센터나 물리적 위치에 설치되어 있으며, 네트워크를 통해 해당 데이터에 접근하고 관리할 수 있습니다.




2. 사례 2: 푸앙이는 저번 주 제주도로 여행을 갔었어요. 비행 중에 예산 계획을 세우려 하는데, 인터넷 연결이 불안정할 것 같아요. 여행 전 미리 예산 데이터를 다운로드해서 오프라인에서도 사용할 수 있으면 좋겠습니다.



```
이 경우에는 **추출 연결**이 적합하다.
추출 연결은 데이터를 Hyper 파일 형태로 저장해 로컬에서 분석할 수 있는 방식이기 때문에 인터넷 연결이 없어도 사용할 수 있다.
따라서 비행 중처럼 네트워크가 불안정한 환경에서는 추출 연결을 사용하는 것이 적절하다.
```

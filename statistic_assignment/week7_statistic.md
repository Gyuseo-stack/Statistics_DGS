### 11.5. 모델 성능 향상을 위한 파생 변수 생성

파생변수는 데이터의 특성을 이용하여 분석 효율을 높이는 것이기 때문에 전체 데이터에 대한 파악이 중요할 뿐만 아니라
**해당 비즈니스 도메인에 대한 충분한 이해가 수반**되어야 함

### 11.6. 슬라이딩 윈도우 데이터 가공

#### 슬라이딩 윈도우: 실시간 네트워크 패킷 데이터를 처리하는 기법
- 현재 시점으로부터 +_ M 기건의 데이터를 일정 간격의 시간마다 전송하는 방식
- **이 방식의 특징**: 각각의 데이터(조각)들이 서로 겹치며 데이터가 전송되는 것.

**데이터가 겹치도록 쪼개어 전송하는 이유**

- 패킷 전송 후 패킷의 전송을 확인받지 않고도 곧 바로 다음 패킷을 보낼 수 있어 네트워크를 효율적으로 사용할 수 있음
- **데이터를 겹쳐 나눔으로써 전체 데이터가 증가하는 원리를 차용한 것이 슬라이딩 윈도우 데이터 가공의 핵심**

### 11.7. 범주형 변수의 가변수 처리

**가변수 처리(더미 변수)**
- 번주형 변수를 0과 1의 값을 가지는 변수로 변환해 주는 것
**가변수를 만드는 이유**
-  범주형 변수는 사용할 수 없고, 연속형 변수만 사용 가능한 분석기법 사용하기 위함 -> 이런 형태는 **이진변수**라고 하며 **불리언 변수**라고 함


선형 회귀분석 or 로지스틱 회귀분석 -> 연속형 변수만 사용 가능

**범주가 3개 이상인 경우의 가변수 처리**

범주가 늘어날수록 변수의 수를 늘리면 됨. 여기서 중요한 점은 **범주의 개수보다 하나 적게 가변수를 만드는 것** 

**변수 간의 독립성을 위해 하나의 범주 가변수를 제거해주는 것이 중요**


### 11.8. 클래스 불균형 문제 해결을 위한 언더샘플링과 오버샘플링

특히 **0과1의 이진분류모델**에서 1의 비율이 매우 적을 때가 많음. 
데이터 불균형이 심하게 되면 원하는 대로 학습이 제대로 이루어지지 않아 예측 정확도가 떨어지게 됨

데이터 불균형 문제를 해결하는 방법은 크게 두 종류로 나뉨

#### 1. 가중치 밸런싱
분류 모델은 전체 정확도를 높이는 방향으로 학습
**모델은 손실을 계산하여 손실이 최소화되도록 학습**
- 가중치 밸런싱은 중요도가 높은 클래스를 잘못 분류하여 더 큰 손실을 계산하도록 조정

EX) 10% 비중의 클래스를 잘못 분류하면 90%의 손실 가중치를 주고, 상대적으로 덜 중요한 90%비중의
가중치를 잘못 분류하면 10% 손실 가중치를 주도록 설정

#### 2. 언더샘플링,오버샘플링
#### 언더샘플링: 큰 비중의 클래스의 데이터를 줄이는 방법
ex.) 1 클래스가 1000개가 있고, 0 클래스 관특치는 10000개가 있다면,1 클래스 1000개, 0클래스 1000개 총 2000개의 관측치로 학습을 하는 것
ex.) **EasyEnsemble**-> 일종의 앙상블 기법,큰 비중의 클래스를 N개의 작은 비중의 클래스와 동일한 크기의 데이터셋으로 분리
<img width="476" height="223" alt="image" src="https://github.com/user-attachments/assets/4fbdd5a4-6700-4f7f-be97-920addeacb24" />
ex.) CNN -> 비중이 큰 클래스의 관측지 중에서 적은 클래스와 속성값이 확연히 다른 관측치들은 제거하여 굳이 학습에 사용하지 않아도 되는 관측지를 제거

#### 오버샘플링: 작은 비중의 클래스 데이터를 늘리는 방법
1.) **랜덤 오버샘플링** : 작은 클래스의 관측치를 단순히 무작위로 선택하여 반복 추출
2.) **SMOTE**: K-Nearest Neighbors 기법 사용. 비중이 작은 클래스의 관측치의 K 최근법 이웃 관측치를 찾아서, 해당 관측치와 K개 최근접 이웃 관측치를 찾음
3.) **ADASYN**: SMOTE기법을 발전시킨 방식. 기존 SMOTE 방식에 오버샘플링할 관측치의 양을 체계적으로 조절할 수 있는 장점
<img width="476" height="183" alt="image" src="https://github.com/user-attachments/assets/7d3c3c62-7a1d-4b62-b11b-2f7a8d2ee807" />

**오버샘플링을 적용할 때에는 먼저 학습 셋과 테스트 셋을 분리한 다음에 적용**

그렇지 않으면 학습 셋과 테스트 셋에 동일한 데이터가 들어가서 과적합 유발 가능


### 11.9. 데이터 거리 측정 방법

#### 유클리드 거리
- 피타고라스 정리를 활용한 것. 관측치 간의 직선거리를 측정하는 것. 값이 0에 가까울수록 데이터 간의 거리가 짧다는 것, 즉 유사도가 높음을 의미

#### 맨해튼 거리
<img width="182" height="141" alt="image" src="https://github.com/user-attachments/assets/84d24861-bbf6-49b6-8495-ed9fdff8f20d" />

- 딥러닝 분야에서 정규화할 때 주로 사용
- 체계적인 도시계획으로 구성된 맨해튼의 격자 모양 도로에서 최단거리를 구하는 원리 사용

#### 민코프스키 거리
- 옵션값을 설정하여 거리 기준을 조정할 수 있는 거리 측정 방법
- 유클리드 거리 수식과 동일하며 단지 제곱 부분을 p-norm값으로 하여 조정
- p값을 1로 설정하면 맨해큰 거리와 동일, 2로 설정하면 유클리드 거리와 동일

#### 체비쇼프 거리
- 민코프스키 거리의 p값을 무한대로 설정했을 때, L max Norm으로도 불림
- 군집 간의 최대 거리를 구할 때 사용
- 0에 가까울수록 유사

#### 마할라노비스 거리
- 유클리드 거리에 공분산을 고려한 거리 측정 방법
- 변수 내 분산과 변수 간 공분산을 모두 반영하여 A와B 거리 계산
- 유클리드의 경우 A(x,y) B(x,y)의 단순 직선 거리를 통해 거리를 측정하지만, 마할라노비스의 경우 X와 Y의 공분산을 고려하여 거리 측정

#### 코사인 거리
- 코사인 유사도(벡터 사이의 각도만으로 두 점 간의 유사도를 측정)
- 두 벡터 사이각을 구해서 유사도를 구함
- 두 점 간의 각도가 작으면 유사도가 높고 각도가 크면 유사도가 낮아짐(0~1의 값을 가짐)
- 크기, 무게와 같은 변수 간의 크기가 중요한 경우에는 적합하지 않음
- 코사인 유사도를 코사인 거리로 환산하는 방법: **1에서 코사인 유사도를 빼 주면 됨**

### 11.1. 결측값 처리

결측값을 처리하기 전에 **EDA**를 통해 다음을 먼저 확인

- 결측값의 비율이 전체 데이터에서 얼마나 되는지  
- 특정 변수에 결측값이 몰려 있는지 여부  
- 빈 문자열(`''`)이 실제 결측값으로 인식되지 않고 있는지
  
### 결측치의 종류


#### 1. 완전 무작위 결측
- 순수하게 무작위로 발생하는 결측
- 결측값을 포함한 데이터를 제거해도 **편향이 거의 없음**

#### 2. 무작위 결측
- **다른 변수의 특성**에 의해 결측이 체계적으로 발생
- 예: 연령대가 높을수록 특정 응답이 누락되는 경우

#### 3. 비무작위 결측
- 결측이 **해당 변수 자체의 특성**에 의해 발생  
- 실제 결측값을 직접 확인할 수 없으므로 구분이 어려움

---

### 결측값 처리 방법

#### 1. 표본 제거법
- 결측값이 심하게 많은 변수는 제거하거나,결측값이 포함된 **행** 자체를 제외
- 전체 데이터에서 결측값 비율이 **10% 미만일 경우** 주로 사용
- 단, 완전 무작위 결측일 때만 적절

#### 2. 평균 대치법

- 결측값을 제외한 **평균값**으로 대체  
- 단점: 표준오차가 축소되어 **p-value가 부정확**해짐 → 통계적 검정 왜곡 가능

#### 3. 보간법
- 시계열 데이터에 자주 사용
- 이전 시점(t-1) 또는 다음 시점(t+1)의 값으로 대체하거나
- 두 시점의 평균으로 대체(단, 인덱스 간격이 불규칙하거나 결측이 연속될 경우에는 선형보간 등으로 보정 필요)

#### 4. 회귀 대치법
- 측값이 있는 변수를 종속변수(y) 로 두고,다른 변수들을 독립변수(X) 로 하여 회귀식을 통해 예측값으로 대체
-**단점:** 분산이 과소 추정될 수 있음
→ **확률적 회귀대치법**을 사용해 인위적으로 오차항을 추가하여 변동성 보정 가능

#### 5. 다중 대치법

- 표본 오차 과소 추정 문제를 해결하기 위해 단순 대치를 여러 번 수행하고 평균을 사용
1. **대치 단계**
가능한 대치값의 분포에서 무작위로 추출하여
n개의 가상 데이터셋 생성
(예: 몬테카를로 방법, 연쇄방정식 사용)
2. **분석 단계**
각 데이터셋을 분석하여 모수 추정치와 표준오차 계산
3. **결합 단계**
각 추정치를 결합하여 최종 추정값 및 표준오차 산출
결측 비율이 높을수록 가상 데이터셋의 개수를 늘려야 검정력이 확보


### 결측값 처리 방법
| 목적     | 함수/메서드                 | 예시                                     |
| ------ | ---------------------- | -------------------------------------- |
| 결측값 제거 | `dropna()`             | `df.dropna()`                          |
| 평균 대치  | `fillna(df.mean())`    | `df['x'].fillna(df['x'].mean())`       |
| 중앙값 대치 | `fillna(df.median())`  | `df['x'].fillna(df['x'].median())`     |
| 최빈값 대치 | `fillna(df.mode()[0])` | `df['x'].fillna(df['x'].mode()[0])`    |
| 시계열 보간 | `interpolate()`        | `df['x'].interpolate(method='linear')` |


### 11.2. 이상치 처리

이상치란 일부 관측치의 값이 전체 데이터의 범위에서 크게 벗어난 아주 작거나 큰 극단적인 값을 갖는 것을 의미
이러한 이상치들은 분산을 과도하게 증가시켜 모델링의 정확도를 감소시킴
이상치는 해당 값을 결측값으로 대체한 다음 결측값 처리를 하거나, 이상치를 제거하는 것이 가장 간단
이 경우들은 추정치의 분산은 감소하지만, 실제값을 과장하여 편향 발생
하한 값,상한 값을 결정한 후 하한 값보다 작으면 하한 값으로 대체, 상한 값보다 크면 상한 값으로 대체하는 관측값 변경
or 이상치의 영향을 감소시키는 가중치를 주는 가중치 조정 방법 사용
평균으로부터 +_n 표준편차 이상 떨어져 있는 값을 이상치로 보는데 보통 n은 3으로 하지만, 분포가 비대칭인 경우 다르게 설정하기도 함
평균은 이상치에 통계량이 민감하게 변하기 때문에 이상치에 강건한 중위수와 중위수 절대 편차를 사용하는 것이 효과적임

분석 도메인에 따라 이상치가 중요한 분석 요인이 될 수 있음


### 11.3. 변수 구간화

데이터 분석의 성능을 향상시키기 위해 이산형 변수를 범주형 변수로 변환
이산형 변수를 범주형 변수로 비즈니스적 상황에 맞도록 변환시킴으로써 데이터의 해석이나 예측,분류 모델을
의도에 맞도록 유도할 수 있음
변수의 값을 일정한 폭이나 빈도로 구간을 나눈 후, 각 구간 안에 속한 데이터 값을 평균,중간, 중앙값, 경곗값 등으로 변화해 주는 것

### 11.4. 데이터 표준화와 정규화 스케일링

독립 변수들이 서로 단위가 다르거나 편차가 심할 때 값의 스케일을 일정한 수준으로 변환시켜주는 
표준화, 정규화 스케일링을 함
독립변수 간 단위가 다른 것은 회귀분석이나 의사결정나무 등 대부분의 데이터 마이닝 모델의 분석 결과에 별다른 영향을 미치지 않기 때문에 그대로 사용해도 무방
표준화는 각 관측치의 값이 전체 평균을 기준으로 어느 정도 떨어져 있는지 나타낼 때 사용
평균은 0으로 변환, 1표준편차 거리는 +_1 2표준편차 거리는 +_2로 변환
Zero-mean으로부터 얼마나 떨어져 있는지를 나타내기 때문에 Z-score로 표햔
표준화는 각 관측치 값에서 평균을 빼준 후 표준편차로 나눠주면 됨

정규화는 데이터의 범위를 0부터 1까지로 변환하여 데이터 분포를 조정하는 방법
0에 가까울수록 작은 값, 1에 가까울 수록 큰 값
정규화는 (해당 값-최솟값)/(최댓값-최솟값)

기본 표준화,정규화 방식은 이상치에 민감하다는 단점을 보완한 스케일링 기법인 RobustScaler도 많이 쓰임
RobustScaler는 데이터의 중앙값(Q2)을 0으로 잡고, Q1과 Q3 사분위수와의 IQR차이를 1이 되도록 하는 스케일링 기법

표준화나 정규화는 특히 거리를 활용한 군집 분석에 필수적

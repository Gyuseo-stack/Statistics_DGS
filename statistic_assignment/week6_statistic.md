## 11.1. 결측값 처리

결측값을 처리하기 전에 **EDA**를 통해 다음을 먼저 확인

- 결측값의 비율이 전체 데이터에서 얼마나 되는지  
- 특정 변수에 결측값이 몰려 있는지 여부  
- 빈 문자열(`''`)이 실제 결측값으로 인식되지 않고 있는지
  
### 결측치의 종류


#### 1. 완전 무작위 결측
- 순수하게 무작위로 발생하는 결측
- 결측값을 포함한 데이터를 제거해도 **편향이 거의 없음**

#### 2. 무작위 결측
- **다른 변수의 특성**에 의해 결측이 체계적으로 발생
- 예: 연령대가 높을수록 특정 응답이 누락되는 경우

#### 3. 비무작위 결측
- 결측이 **해당 변수 자체의 특성**에 의해 발생  
- 실제 결측값을 직접 확인할 수 없으므로 구분이 어려움

---

### 결측값 처리 방법

#### 1. 표본 제거법
- 결측값이 심하게 많은 변수는 제거하거나,결측값이 포함된 **행** 자체를 제외
- 전체 데이터에서 결측값 비율이 **10% 미만일 경우** 주로 사용
- 단, 완전 무작위 결측일 때만 적절

#### 2. 평균 대치법

- 결측값을 제외한 **평균값**으로 대체  
- 단점: 표준오차가 축소되어 **p-value가 부정확**해짐 → 통계적 검정 왜곡 가능

#### 3. 보간법
- 시계열 데이터에 자주 사용
- 이전 시점(t-1) 또는 다음 시점(t+1)의 값으로 대체하거나
- 두 시점의 평균으로 대체(단, 인덱스 간격이 불규칙하거나 결측이 연속될 경우에는 선형보간 등으로 보정 필요)

#### 4. 회귀 대치법
- 측값이 있는 변수를 종속변수(y) 로 두고,다른 변수들을 독립변수(X) 로 하여 회귀식을 통해 예측값으로 대체
-**단점:** 분산이 과소 추정될 수 있음
→ **확률적 회귀대치법**을 사용해 인위적으로 오차항을 추가하여 변동성 보정 가능

#### 5. 다중 대치법

- 표본 오차 과소 추정 문제를 해결하기 위해 단순 대치를 여러 번 수행하고 평균을 사용
1. **대치 단계**
가능한 대치값의 분포에서 무작위로 추출하여
n개의 가상 데이터셋 생성
(예: 몬테카를로 방법, 연쇄방정식 사용)
2. **분석 단계**
각 데이터셋을 분석하여 모수 추정치와 표준오차 계산
3. **결합 단계**
각 추정치를 결합하여 최종 추정값 및 표준오차 산출
결측 비율이 높을수록 가상 데이터셋의 개수를 늘려야 검정력이 확보


### 결측값 처리 방법
| 목적     | 함수/메서드                 | 예시                                     |
| ------ | ---------------------- | -------------------------------------- |
| 결측값 제거 | `dropna()`             | `df.dropna()`                          |
| 평균 대치  | `fillna(df.mean())`    | `df['x'].fillna(df['x'].mean())`       |
| 중앙값 대치 | `fillna(df.median())`  | `df['x'].fillna(df['x'].median())`     |
| 최빈값 대치 | `fillna(df.mode()[0])` | `df['x'].fillna(df['x'].mode()[0])`    |
| 시계열 보간 | `interpolate()`        | `df['x'].interpolate(method='linear')` |


## 11.2. 이상치 처리

- **이상치**란 일부 관측치의 값이 전체 데이터의 범위에서 크게 벗어난 극단적인 값을 의미 
- 이상치는 **분산을 과도하게 증가**시켜 모델의 정확도를 떨어뜨릴 수 있음

---

### 이상치 처리의 기본 접근법

1. **결측값으로 대체 후 결측값 처리**
   - 이상치를 `NaN`으로 대체한 뒤, 결측값 처리 방법(평균 대치, 회귀 대치 등)을 적용

2. **이상치 제거**
   - 이상치를 직접 삭제하여 분석에서 제외한다.
   - 단, **추정치의 분산은 감소하지만 편향이 발생할 수 있음**에 유의

3. **하한/상한값 대체**
   - 하한값과 상한값을 설정한 후,
     - 하한보다 작으면 하한값으로,
     - 상한보다 크면 상한값으로 대체한다.

4. **가중치 조정**
   - 이상치의 영향을 줄이기 위해 낮은 가중치를 부여


### 이상치 판별 기준

- **평균 ± n × 표준편차(σ)** 기준 사용  
  - 보통 `n = 3`으로 설정하지만, 분포가 비대칭한 경우 다르게 조정 가능

- **중위수와 중위수 절대 편차** 활용  
  - 평균은 이상치에 민감하므로, **중위수와 MAD**를 이용한 **강건한** 기준이 효과적


### 분석 시 주의점

- 이상치는 단순히 오류가 아닌, **도메인 특성상 중요한 요인**일 수 있다.  
  - 예: 금융 데이터의 비정상 거래, 의료 데이터의 희귀 질병 수치 등  
- 따라서, 이상치 제거 여부는 **분석 목적과 맥락에 따라 판단**해야 한다.



### 11.3. 변수 구간화

- **데이터 분석의 성능을 향상**시키기 위해 **이산형 변수를 범주형 변수** 로 변환
- 변수 구간화를 통해 **데이터 해석, 예측, 분류 모델**의 성능을 **비즈니스적 의도에 맞게 조정**

- **이산형 변수 → 범주형 변수 변환**
  - 변수의 값을 **일정한 폭** 또는 **빈도** 로 구간화한다.
  - 각 구간(bin)에 속한 값을 **평균, 중앙값, 경곗값 등 대표값으로 변환**
ex)

구간을 나누는 그 밖의 방법으로 **클러스터링이나 의사결정나무와 같은 머신러닝 기법**을 사용할 수도 있음
- **클러스터링**은 타깃 변수 설정이 필요 없이 구간화할 변수의 값들을 유사한 수준으로 묶어줌
- **의사결정나무**는 타깃 변수를 설정해 구간화할 변수의 값을 타깃 변수 예측에 가장 적합한 구간으로 나누어 줌

### 구간화 성능 평가 지표

#### 1. WOE
- 독립 변수의 각 구간이 **종속 변수(True/False)** 를 얼마나 잘 구분하는지를 수치로 표현.

#### 2. IV
**독립 변수의 예측력**을 나타내는 지표.  
- WOE를 기반으로 계산되며, IV 값이 높을수록 변수의 **판별력이 높음**을 의미
IV 수치 높을수록 True,False잘 구분할 수 있는 정보량 많다는 것

- 변수 구간화를 통해 **모델의 해석력**과 **정확도**를 동시에 높일 수 있다.
- 특히 **신용평가, 고객 세분화, 리스크 예측** 등의 도메인에서 WOE/IV 기반 구간화는 **모델 설명력 향상**에 유용

  
## 11.4. 데이터 표준화와 정규화 스케일링

- **독립 변수 간 단위가 다르거나 편차가 심할 때**, 값을 일정한 수준으로 맞추기 위해 **스케일링** 을 수행
- 스케일링은 **모델의 수렴 속도 향상, 성능 안정화, 거리 기반 알고리즘의 정확도 개선**에 도움


### 표준화
- 각 관측치의 값이 전체 평균을 기준으로 어느 정도 떨어져 있는지 나타낼 때 사용
- 평균은 0으로 변환, 1표준편차 거리는 +_1 2표준편차 거리는 +_2로 변환
- **Zero-mean**으로부터 얼마나 떨어져 있는지를 나타내기 때문에 **Z-score**로 표현
- 표준화는 각 관측치 값에서 평균을 빼준 후 표준편차로 나눠줌

### 정규화
- 데이터의 범위를 0부터 1까지로 변환하여 데이터 분포를 조정
- 0에 가까울수록 작은 값, 1에 가까울 수록 큰 값
- 정규화는 **(해당 값-최솟값)/(최댓값-최솟값)**

### RobustScaler
- 기본 표준화,정규화 방식은 이상치에 민감하다는 단점을 보완한 스케일링 기법
- RobustScaler는 데이터의 중앙값(Q2)을 0으로 잡고, Q1과 Q3 사분위수와의 IQR차이를 1이 되도록 하는 스케일링 기법
